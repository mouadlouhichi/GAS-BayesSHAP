# main_results

Consolidated paper-facing experiment outputs (tables/figures) for
GAS-BayesSHAP v11.0.  All `paper_*` artifacts are generated by the CLI
scripts under `scripts/` (see the table below); the demo notebooks
(`SHAP_WINE_GAS.ipynb`, `AIR_QUALITY_GAS.ipynb`) are **smoke-test demos**
(ε=15, budget=1500 — loudly labeled in-notebook; set `PAPER_GRADE=True` for
the paper settings) and are NOT the paper drivers.

## Honest reporting conventions (used across all artifacts)

- `num_coalition_evals_this_call` = **unique** coalition evaluations
  (cache misses); `stage2_attempted_total` = attempted Stage-2 draws
  (budget accounting); `num_model_evals_this_call` = model forward passes.
- `simultaneous_coverage_rate` is an **empirical event frequency**; for the
  finite-population mode it is accompanied by `reported_coverage_level`,
  `delta1_coupon`, `coupon_threshold_satisfied`,
  `certificate_at_nominal_level` — a nominal 1−δ certificate is claimed
  only when the coupon thresholds hold (Corollary E).
- Matched-budget curves are **matched nominal-budget** comparisons (GAS
  `max_budget` vs KernelSHAP `nsamples`), with actual costs reported
  alongside; they are not a perfect matched-query benchmark.
